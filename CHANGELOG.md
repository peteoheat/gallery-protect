# Changelog

## 1.0.0 - 2026-10-08

- Initial reusable Wrangler deployment package.
- PBKDF2-SHA-256 password hashing with 100,000 iterations.
- Signed seven-day event session cookies.
- R2-backed per-event password protection.
- Support for multiple custom domains and R2 buckets.
- Local Wrangler configuration generator.
- Optional GitHub Actions deployment.
