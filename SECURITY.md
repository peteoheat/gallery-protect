# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you find a security issue, contact the repository maintainer privately through the GitHub account associated with this repository.

Do not include passwords, `AUTH_SECRET`, private gallery content, or other sensitive information in a public issue.

## Scope

Security reports involving authentication, password handling, session cookies, path traversal, access to R2 objects, or accidental disclosure of `.secrets` are particularly important.
